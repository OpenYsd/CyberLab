Microsoft Visual C++ runtime
----------------------------
This copy contains no Microsoft Visual C++ runtime file. CyberLab needs
Microsoft Visual C++ Redistributable (x64), version 14.44 or later, which
you install from Microsoft:
  https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist
Start CyberLab with "Start CyberLab.cmd", which checks for it first.
